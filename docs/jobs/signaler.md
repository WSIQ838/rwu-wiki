# Signaler

Run a signal box: set routes, move points and keep trains safely apart on the live track diagram.

## Ranks

| Trainee Signaler | TS | 0 |
| Qualified Signaler | QS | 300 |
| Senior Signaler | SS | 1500 |
| Signaling Instructor | SI | Awarded by staff |
| Signaling Supervisor | SSup | Awarded by staff |
